# Day 11 — Static Routing Commands

## Next-Hop Static Route

ip route <destination-network> <subnet-mask> <next-hop-IP>

Example:

ip route 192.168.2.0 255.255.255.0 10.0.0.2

## Exit-Interface Static Route

ip route <destination-network> <subnet-mask> <exit-interface>

Example:

ip route 192.168.2.0 255.255.255.0 GigabitEthernet0/1

## IPv4 Default Route

ip route 0.0.0.0 0.0.0.0 <next-hop-IP>

Example:

ip route 0.0.0.0 0.0.0.0 10.0.0.2

## Verification

show ip route
show ip route static
show ip route <destination-network>
show ip interface brief

## Connectivity

ping <destination-IP>
traceroute <destination-IP>
