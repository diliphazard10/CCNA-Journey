# CCNA 200-301 Journey 🚀

My hands-on journey toward the Cisco CCNA 200-301 certification.

This repository documents my daily learning, labs, troubleshooting exercises, configurations, and notes.

- Pass the CCNA 200-301 exam
- Build strong networking fundamentals
- Develop practical Cisco networking skills
- Build a public networking portfolio
- Prepare for a career as a Network Engineer
